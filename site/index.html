Everything you need to read a repo

And nothing you don't. auri isn't an editor — it's a place to look at your code and what changed in it.

⇆

Side-by-side diffs

Old and new, next to each other, with syntax highlighting. Jump between changes with n / N.

▤

File explorer

A lazy file tree with git status on every row and a highlighted, read-only file viewer.

±

Stage & commit

Stage, unstage and discard changes, write a message and commit — without leaving the view.

◷

History

Browse past commits and open the diff of any file they touched.

✦

AI commit drafts

Optional: Ctrl-G drafts a message from your staged diff with Codex CLI or opencode. It never commits for you.

◐

Keyboard or mouse

Vim-style keys, clickable buttons and tabs, draggable dividers. Your layout is remembered.

Why “auri”?

Auri is Latin for of gold. Look at Albireo, in the constellation Cygnus, through a small telescope and one star becomes two: a golden one and a blue one, side by side.

Two views of the same spot, each showing what the other doesn't. That's what a diff is.
